## Top button

| Gesture | Action |
| --- | --- |
| Press | Search for the phone. In Local mode, ends Local mode. |
| Hold, then release | Local mode: the box broadcasts its own Wi-Fi so the phone reaches the box page without a router. With no phone saved yet, this is Setup mode. |

The box acts about a second after you let go: the PiSugar 3 reports a hold only on release.

The box looks for the phone by itself only when it starts and when you pull the cable. After that, press the top button or tap **Reconnect iPhone** on the box page.

## Factory reset

Reset proves you are next to the box:

1. Start a reset on the box page.
2. Press the top button the number of times the page shows (5 to 8).
3. After 2 seconds without a press, the reset is armed. Hold the top button within 30 seconds to erase the box.

A wrong count, a hold during the count or a timeout cancels it. A Raspberry Pi box without the button asks you to type the box name instead.

## Power button

OpenLolo keeps the PiSugar 3 defaults. Power on with a short press, then press and hold. A long press cuts power at once.

## Auto sleep

On battery, the box turns itself off when no iPhone is connected and nothing has used it for the time set in **Settings > Auto sleep** (30 seconds, or 1 to 5 minutes, as on an iPhone; 3 minutes by default, or Off). It never turns off while plugged into power. Before it turns off, the status LED flickers fast for 10 seconds: press the top button, or tap **Keep on** on the box page, to keep it on. Press the power button to turn it back on.

<Callout type="warn">A long press is not a clean shutdown. Shut down from the box page when you can.</Callout>

## Status LED

| LED | Meaning |
| --- | --- |
| Fast blink | Local or Setup mode: the box's own Wi-Fi is on |
| Steady on | Phone connected |
| Slow blink | Looking for the phone |
| Fast flicker | Auto sleep: turning off in 10 seconds. Press the top button to keep it on |
| Off | Not connected and not looking |
