---
title: What the installer prints
description: The LAN address, the fingerprint and the setup card.
---

At the end, the installer prints:

- The LAN address of the box page and its certificate fingerprint
- The remote MCP URL, if remote access is on
- The **setup card**: the box's Wi-Fi name, password and a QR code to join it from the iPhone

Keep this terminal open: you need the setup card in [Join the setup Wi-Fi](/docs/pair-your-lolobox/open-the-setup-page).

To print the setup card again:

```sh
sudo -u openlolo /opt/openlolo/current/.venv/bin/openlolo setup-card
```

Your build is ready for the shared setup guide. Next: [Turn on your LoloBox](/docs/pair-your-lolobox/turn-on-your-lolobox).
