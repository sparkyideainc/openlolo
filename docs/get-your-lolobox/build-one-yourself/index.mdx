Building your own involves preparing a memory card and running installation commands from a computer. Start with the recommended build unless you already have one of the other boards.

Check [what you need](/docs/get-your-lolobox/build-one-yourself/what-you-need) before buying parts.

| Build | Size | Battery | Status |
| --- | --- | --- | --- |
| [Radxa ZERO 3W + PiSugar 3](/docs/get-your-lolobox/build-one-yourself/radxa-zero-3w-pisugar-3) | Pocket | 1200 mAh PiSugar 3 | Recommended |
| [Raspberry Pi 4](/docs/get-your-lolobox/build-one-yourself/raspberry-pi-4) | Desk | None (wall power) | Tested |
| [Raspberry Pi 3](/docs/get-your-lolobox/build-one-yourself/raspberry-pi-3) | Desk | None (wall power) | Tested |
