---
title: Troubleshooting by symptom
description: Common problems and fixes.
---

| Symptom | Fix |
| --- | --- |
| Setup Wi-Fi does not show | {/* TODO */} |
| `TRUST_REQUIRED` | Plug the iPhone in by USB, unlock it and tap Trust |
| `WIFI_PAIRING_REQUIRED` | Pair once over USB to create the Wi-Fi pairing record |
| Developer disk image does not mount | The box needs internet access after each phone reboot |
| Remote access failed | Rerun `remote-access.sh`; the box still works on the LAN |
| Box offline, LED off, on battery | Auto sleep turned it off. Press the PiSugar power button, or plug in power. Change the idle time in Settings > Auto sleep |
| `DEVICE_DISCONNECTED` from an AI | The box looks for the phone only at start-up and when the cable is pulled. Press the top button or tap Reconnect iPhone |
