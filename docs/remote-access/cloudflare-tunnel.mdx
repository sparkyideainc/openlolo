---
title: Cloudflare Tunnel
description: Use your own domain instead of Tailscale.
---

```sh
curl -fsSL https://openlolo.com/install.sh | sudo sh -s -- --remote cloudflare
```

Log in to Cloudflare and pick your domain when asked. The box takes `openlolo-<board id>.<your domain>` unless you pass `--hostname`.
