# Design notes

Engineering notes for contributors. Nothing here is published; the user documentation is at
[openlolo.com/docs](https://openlolo.com/docs).

- `hardware/`: board and accessory reference notes, with dated bench findings. Device code
  cites them as the source for register values and timings.
- `plans/`: design plans for work in progress.
- `plans/archive/`: implemented plans, kept for their reasoning and measurements.

Every plan starts with a status line: the date, whether it is a plan, in progress or
implemented, and the document that supersedes it, if any. When behaviour ships, move what users
need into the user documentation and keep the bench evidence here.
